# AKAN Devices and Solutions Website

This repository contains the source code for the AKAN Devices and Solutions website, a multi-page catalog showcasing their products.

## Website Structure

*   `index.html`: The main landing page with an introduction and links to the main product categories.
*   `access-control.html`: A detailed page for all Access Control System products.
*   `iot-devices.html`: A detailed page for all IoT Device products.
*   `smart-solutions.html`: A detailed page for all Smart Solution products.
*   `style.css`: The stylesheet that provides the design and layout for all pages.
*   `images/`: Contains all images, including the company logo.

## E-commerce Functionality Note

Please be aware that this website serves as a **visual template** and does **not** have a functional e-commerce backend.

*   The **"Buy Now"** buttons are currently placeholders.
*   The **payment method icons** in the footer are for display purposes only.

To enable online purchases, you will need to integrate the "Buy Now" buttons with a third-party payment processing service, such as:
*   [Stripe](https://stripe.com/)
*   [PayPal](https://www.paypal.com/)
*   [Square](https://squareup.com/)

Each of these services provides detailed documentation on how to add their payment gateways to a website. This typically involves adding a specific script to your HTML and configuring the buttons to trigger a payment flow.
